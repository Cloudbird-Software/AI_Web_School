# L0 架构宪法（CONSTITUTION）
> 本文件是全系统的最高约束。任何规格、代码、agent 行为与本文件冲突时，以本文件为准。
> 变更规则：仅人类可修改；每次修改必须在 specs/adr/ 新增一条 ADR 记录理由。
> 版本：v2.0（2026-07-30）｜对应架构：《工程架构设计方案 v2》+ ADR-0003（愿景 v2 与波次重规划）
> v1.0 → v2.0：新增第零部分「北极星愿景 V1–V6」；新增公理 A8–A10；新增铁律 D9–D11；新增纪律 P9；新增禁令 X11–X13。理由见 specs/adr/0003-vision-v2-and-wave-replan.md。

## 第零部分：北极星愿景（V1–V6）

> 愿景条款回答"我们为什么存在、十年后剩下什么"。它不替代公理，但当技术选择出现分歧时，选更有利于愿景达成的一方。

- **V1 我们卖的是确定性，不是题**：产品的价值主张是"知道孩子哪里弱、接下来该练什么"。任何功能若不能缩短「作答 → 归因 → 开方 → 见效」这条链路，都是次要功能。
- **V2 数据飞轮是唯一不可复制的资产**：内容可被抄、模型会被追平，只有"中文小学题目的真实作答参数（难度/区分度/错误模式命中率）"是十年复利。因此每一次触达学生的作答都必须可回流、可归因、可重算；宁可少上一个功能，不可丢一条作答证据。
- **V3 闭环链路优先于单点能力**：系统的完成度以端到端闭环衡量——知识穷尽 → 无限出题 → 最佳实践组卷 → 作答回流 → 弱项定位 → 定向练习/测量 → 参数标定 → 反哺出题。任何波次的出口必须是"一条更完整或更可信的闭环"，而非"多了几个模块"。
- **V4 护城河逐层加深**：产能层（AI 出题，入场券）→ 质量层（校验门，难追赶）→ 诊断层（错误模式库，很难追赶）→ 数据层（实测参数，不可复制）。工程资源优先投向更深的层；产能层达到"够用"即停止镀金。
- **V5 单位经济性内建**：单份内容的生产成本（AI token、渲染、存储、人工抽检）必须由系统自动归集到 item_revision / 交付单，不依赖事后人工统计；成本不可见的功能视为未完成。
- **V6 上线即真实用户**：一切能力以"真实小学生在真实设备上完成一次练习并拿到弱项报告"为验收终点。模拟器、演示脚本只是中间证据，不构成交付。
> 商业路线（三年三段）与合规红线以 ADR/智能个性化练习项目-业务全景说明书.md 为准：第一年小学数学单点打透并启动飞轮；第二年英语/语文基础层与托管机构 B 端；第三年自适应与测量产品化。合规红线（不做学科培训、不承诺提分、不使用教材/真题原文、家长授权前置、不排名）为不可谈判项。

## 第一部分：架构公理（A1–A7）

- **A1 题是数据，卷是视图**：全系统只有一个内容资产域；试卷/练习/诊断均为（内容快照, 约束集, 种子）的确定性输出。禁止任何产品形态另立题库。
- **A2 校验门文化**：AI 与人工作物过同一扇门；未通过校验门的产物**物理上无法**进入已发布区。
- **A3 数据飞轮（十年）**：原始作答只增不改；评分/估计/推断方法的演进只产生新版本，永不推翻历史数据。
- **A4 可追溯即入水口**：凡触达用户的题必须携带可回流身份的编码；无编码的渲染产物不得发布。
- **A5 学科中立 by construction**：核心平台代码零学科、零学段特判；任何学科（含数学）只能以 SubjectPack 存在，学段差异只能以 GradeBandPack 存在。
- **A6 学段是一等维度**：低/中/高学段的呈现、交互、时长、合规差异必须有类型化承载（学段包），禁止散落各处的年级 if 分支。
- **A7 生产线多元对等**：母题化是生产优化而非模型前提；A/B/C/D 四级生产线输出统一 ItemVersion，共用同一入库服务、同一校验门、同一证据链。
- **A8 宪法即测试（承诺兑现度）**：本宪法每一条必须在 `specs/contracts/TRACEABILITY.md` 的「强制实证矩阵」中登记至少一项可执行实证（DB 约束/迁移、契约测试、CI 检查、端到端测试）。**没有实证的条款一律视为未实现**，禁止在任何文档、注释、汇报中宣称其"已强制"。
- **A9 在线链路与内容资产同级**：面向学生的在线链路（会话/作答/评分/报告/交付）的正确性等级与内容资产等同——单一事务边界、幂等、并发安全、明确的 SLO 与降级路径，缺一不可，且必须有测试承载。
- **A10 增长闭环内建**：获客→体验→转化→留存的关键计量（漏斗事件、单位成本、交付状态）由系统内建产出，不依赖事后人工统计；一律以 student_alias 维度聚合，且不得因此突破 D8（不排名）与 D7（PII 隔离）。

## 第二部分：数据与内容铁律（D1–D11）

- **D1 三本只增不改的账**：内容版本账（Item/Material/Corpus 全版本化）、作答事件账（response_event append-only，DB 权限禁 UPDATE/DELETE）、校验签发账（gate_run/verdict/门证书只增不改）。
- **D2 门的数据库级强制**：发布事务必须持合法门证书，由数据库触发器强制；任何绕过写入服务的直写必须失败——此行为必须有自动化测试。
- **D3 内容寻址身份**：A/B 级实例 id = H(模板版本, 规范化参数, 引擎/学科包/语料库 digest, locale)；同一内容必须得到同一 id。
- **D4 双类型注册表纪律**：作答交互与评分器只能来自平台注册表；学科包只能复用与参数化，禁止私造作答/评分结构；新增类型须平台评审注册。
- **D5 参数分场景**：item_param 的 source（先验/实测）与 purpose_scope（practice/diagnosis/measurement）必须分开存储、分开估计，禁止跨场景混估。
- **D6 估计器可替换**：估计/评分/掌握度均为纯批处理，输入快照绑定、版本可切换（ActiveModelPointer）；历史报告永远引用当时版本。
- **D7 PII 隔离**：学生直接标识只允许存在于独立 PII 保险库 schema；主库只有 student_alias_id；LLM/TTS 调用前必须剥离 PII。
- **D8 不排名**：代码层不得提供跨用户成绩排名的查询路径；对外呈现一律等级化。
- **D9 主体绑定与最小权限**：任何触达数据的请求必须携带已认证主体；学生主体只能读写自身 student_alias_id 关联的数据；教研/运维/机构端权限独立、可审计、可撤销；除健康检查与公开静态资源外不存在匿名端点；服务端凭证（含工作台 token）永不经任何 API 回传。
- **D10 AI 可回放**：所有生成式调用（出题/改写/评分/TTS）必须经统一 AI 总线并落台账：模型标识、模型版本、prompt 版本、token 与成本、关联产物 id 缺一不可；AI 参与的评分必须把模型版本写入 scoring_trace，十年后可定位"当时是哪个模型给的分"；PII 剥离失败必须 fail-closed（拒绝调用），禁止任何降级放行开关。
- **D11 写路径事务纪律**：领域服务不得自行 commit，事务边界由最外层调用方（API/作业）确定；一次业务写入是一个事务，作答事件与会话状态不得分裂；对外写入端点必须幂等（幂等键或天然幂等）并对并发提交加锁；审计类副作用必须走显式独立事务，其失败必须可观测而非静默丢失。

## 第三部分：开发纪律（SDD 九条）

- **P1 规格先行**：无规格无代码。PR 必须引用任务卡，任务卡必须引用规格（specs/）路径。
- **P2 构建者不自证**：任何产物由独立 Verifier（不同模型家族）验收；Builder 的自测报告仅作线索。
- **P3 机器信号唯一事实**：CI、契约测试、黄金数据集、黄金路径为唯一事实源；与 agent 汇报矛盾时信信号。
- **P4 黄金路径常绿**：30 抽样题型端到端链路任何合入不得破坏；红过 24 小时即全项目最高优先级。
- **P5 契约冻结**：波内冻结的 L1 契约只增不改；修改必须走契约变更申请→影响面分析→人类批准。
- **P6 失败升级制**：同一任务失败 2 次必须升级（更强模型/Judge/人类）；禁止静默重试；禁止"绕过式完成"。
- **P7 一切留痕**：每个 PR 记录任务卡 id、执行模型、token 成本；遥测 JSONL 入 .agent/telemetry/。
- **P8 小而绿**：任务卡粒度 = 单 agent 一次会话可完成且可独立验收（目标 2–6 小时）；大任务先拆卡。
- **P9 实证矩阵常绿**：每个波次出口必须刷新「强制实证矩阵」（A8）并全绿；波内新增/修改的宪法条款必须在同波补齐实证；矩阵中出现"声称已强制但无实证"的条目，等同黄金路径变红，为全项目最高优先级。

## 第四部分：绝对禁令（X1–X13）

- **X1** 禁止删除、修改、弱化任何既有测试（含断言、黄金样例、契约测试）；新增 skip/xfail 必须附理由并经人类批准。
- **X2** 禁止 agent 伪造成功：未完成却汇报完成、隐藏失败日志、修改验收脚本使其通过。
- **X3** 禁止任何密钥/凭证进入仓库、日志、prompt。
- **X4** 禁止在 owner_module 之外创建或修改文件（任务卡显式授权除外）。
- **X5** 禁止在用户请求链路中临时调用生成式 AI 出题；在线只消费已发布实例池。
- **X6** 禁止核心域代码 import 任何学科包/学段包（CI 静态扫描强制）。
- **X7** 禁止手工直接修改数据库（一切 DDL 走迁移工具；一切数据变更走迁移或管理命令）。
- **X8** 禁止引入新依赖而不更新锁定文件与依赖评审说明。
- **X9** 禁止把整库/大文件塞进 prompt：上下文一律以路径索引按需读取。
- **X10** 禁止在无备份/无演练情况下执行不可逆操作（删数据、改历史事件、清缓存区外对象存储）。
- **X11** 禁止"测试与实现互证"：为让测试通过而伪造被测数据形态或弱化被测语义（例：把内容 digest 当主键写入以骗过查重测试、用 fixture 预插生产环境不存在的占位行掩盖 FK 缺陷）。发现即视同 X2 伪造成功。
- **X12** 禁止合规降级：PII 剥离失败、家长授权缺失、许可未登记时，以"宁可少调用""先跑通再补"等理由放行；合规失败一律 fail-closed。
- **X13** 禁止无主体的数据访问路径：新增端点若未绑定认证主体与授权规则，即使功能正确也不得合入。
