## 一、背景与动机

D9「任何触达数据的请求必须携带已认证主体」的 Go 侧落地（T-W5-005/006，#70/#85）
使实际 API 行为已与冻结的 openapi-v1.yaml 产生不可调和的偏差：v1 假设匿名访问 +
请求体自报身份，实际实现是 Bearer 令牌 + 令牌内身份（铁律 8：不信任请求体 alias）。
按 P5「契约变更申请 → 影响面分析 → 人类批准」流程，就地改冻结文件被禁止
（v1 零 diff，contract-watch 继续 guard v1）——本 ADR 申请签发 v1.1。

## 二、变更清单（v1 → v1.1）

| # | 变更 | 类型 | 依据 |
|---|---|---|---|
| 1 | 新增 `components.securitySchemes.bearerAuth`（http bearer，短期 HMAC 不透明令牌） | 加性 | T-W5-005 core/auth |
| 2 | 全部业务端点声明 `security: [bearerAuth: []]`；`/health` 保持匿名（存活探针，D9 明文豁免） | 变更 | 006 中间件接线矩阵 |
| 3 | 全部业务端点补 401/403 响应，body = 单字段 `error_class`（初稿 5 值；**修订（对抗审查 B1）**：终值见第 8 项 = errmap.go 全集 + not_implemented 共 9 值），零内部细节 | 加性+显式化 | 005/008 脱敏纪律 |
| 4 | `POST /sessions` 请求体（StartSessionRequest）移除 `student_alias_id` 属性——身份取自令牌 Principal | 破坏性 | 铁律 8（010 的体判据机器强制） |
| 5 | `GET /sessions/{id}/next` 200 响应由 `additionalProperties: true` 改为显式 `NextItemResponse`（done 必填；placement_token 可空 + item_version_id + item；`additionalProperties: false`）——**修订（对抗审查 B2）**：source_ref 不入本响应（域内为对象形态且属作答事件账），A4 由 placement_token/item_version_id 承载 | 显式化 | A4 追溯，验收 #3 |
| 6 | 429 语义进入 ErrorClass 枚举（008 限流已实装） | 加性 | T-W5-008 |
| 7 | 文件级 info 元数据（title/version=1.1.0-draft、x-frozen: false、x-adr/x-supersedes）随新文件自带 | 加性 | 对抗审查 m1 |
| 8 | ErrorClass 枚举 = errmap.go 常量全集（8 值）+ not_implemented（占位路由）共 9 值；NextItemResponse 以 done 必填 + 可空 placement_token 建模（done 情形互斥消解）；source_ref 不在本响应声明（属 response_event 账对象形态） | 显式化 | 对抗审查 B1/B2 |

## 三、破坏性影响面分析

| 受影响方 | 影响 | 处置 |
|---|---|---|
| Python 模拟器（tests/simulator，冻结只读） | v1 形态调用将收到 401 | 冻结件不接新功能；Go E2E 全绿后归档（issue #34 §三重写策略），期间 v1/v1.1 并行期由网关/适配层兜底 |
| Streamlit 工作台（冻结，W7 学生端取代） | 同上 | 不再迭代；workbench 签发闭环已随冻结固化 |
| 未来小程序/学生端（W7 起 TS） | 无影响——直接按 v1.1 开发 | W7 端点契约以 v1.1 签发版为准 |
| 既有 openapi 运行期扫描测试（api 包） | 扫描基准文件不变（v1）；v1.1 校验为新增测试 | 兼容期双跑 |

## 四、兼容期策略与回滚

1. **并行期**：v1 冻结文件零改动继续生效（contract-watch 不变）；v1.1 状态
   `x-frozen: false` 且**不入 FROZEN.txt 清单**——登记由 owner 于签署时执行
   （contract-drift 引擎按扩展名分类把 FROZEN.txt 当 JSON 解析，非 JSON 即
   fail-closed 红，追加动作按 P6 升级 owner）。
2. **签署后**：v1.1 升格冻结（x-frozen: true 由 owner 提交翻转）；Go 服务端点行为
   与 v1.1 的一致性由契约测试双向锁定。
3. **回滚**：v1.1 为新增文件，回滚 = 删除该文件 + FROZEN.txt 摘除登记行
   （FROZEN.txt 语义为「只增不改」——摘除须同样走契约变更流程并引用本 ADR）；
   v1 全程未动，零回滚风险外溢。
