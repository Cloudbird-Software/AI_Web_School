# 智能个性化练习项目 · 业务全景说明书

> 用途：本文档只讨论业务与产品，供与合作方、顾问、潜在合伙人讨论发展策略之用。文末附关键数据来源与开放讨论点。

---

## 一、一句话说明

我们用一套自研的 AI 出题引擎，为小学生家长提供**"先诊断、再开方、后练习"的个性化学习材料服务**——卖的不是题，而是"知道孩子哪里弱、接下来练什么"的确定性。

## 二、为什么做这件事：四个正在汇合的窗口

1. **需求真实且被验证过。**家长不缺少题（网上题是免费的），缺的是三样东西：不知道孩子哪里弱、不知道接下来练什么、没时间盯。学习机厂商（学而思、作业帮、科大讯飞）用2500~6000元的硬件证明了家长愿意为"AI诊断+精准练习"付高价——我们用百分之一的价格切同一个需求。
2. **市场够大且在向线上转移。**国内教辅零售市场约800亿元量级；其中内容电商（抖音等）渠道的教辅销售占比已达约27%，同比增速约70%，是所有渠道中最快的。双减之后，家长自购练习的需求持续上升（非同步类教辅占比四年间从约18%升至约26%）。
3. **生产成本出现历史性拐点。**大模型+参数化生成技术，使高质量练习题的边际生产成本趋近于零——历史上题库行业"题目靠专家手写"的最大瓶颈被解除。
4. **监管淘汰了大量供给。**双减对学科类培训（一对一、直播课等）持续高压，但**数字化学习材料内容**不在其列——这给我们留出了合规的空白地带，同时抬高了小作坊同行的生存难度。

## 三、产品体系：三种用途，一条生产线

所有产品都由同一套引擎产出，区别只在"组卷逻辑"：

| 用途 | 逻辑 | 对应产品 |
|---|---|---|
| **练习**（干预） | 变式链递进、高成功率、解析是主体、易混淆点交错 | 专项练习包、同步练习订阅 |
| **诊断**（归因） | 每题单知识点、干扰项对应具体错误类型、题量小 | 单元诊断包（卷+弱项报告） |
| **测量**（计量） | 双向细目表、难度配比、信度区分度 | 模拟考试（后期产品） |

**诊断报告是差异化的核心**：普通资料号只能给"对错"，我们的报告能指出"孩子错在哪种类型的理解上"（例如：不是"小数比较不会"，而是"认为位数多的小数更大"这一典型迷思），并自动配上针对性练习。这道"诊断→开方→练习"的闭环，是目前9.9元资料号无法复制的。

## 四、获客与转化漏斗（渠道：抖音、小红书 → 自有小程序）

```
内容层：卷子翻页视频/图文（内容即产品演示，零额外内容成本）
  ↓ 平台合规触点（企业号自动回复、粉丝群；内容本身不带二维码）
承接层：抖音小程序（平台内闭环）+ 微信小程序（私域）
  ↓
体验层：在线做题或纸质拍照/录入批改 → 即时生成弱项报告 → 免费送3次针对性练习
  ↓
变现层：付费阶梯（见下）
  ↓
私域层：公众号 + 打印包裹卡 + 企业微信
```

**付费阶梯与角色：**

| 产品 | 定价 | 角色 |
|---|---|---|
| 免费层（练习+批改+弱项报告） | 0元 | 获客与价值证明 |
| 弱项突破包（3套针对卷+错题讲义+复测卷） | 4.9元 | 首单转化器（低于决策阈值，且是个性化的） |
| 月度包（每周同步练+双周诊断） | 29.9元/月 | 习惯养成 |
| 学期订阅 | 199元/学期 | 利润主体 |
| 学年托管（含打印成册寄送） | 399元/年 | 高客单+实物触点 |
| 托管机构版（日更练习+批改支持） | 300~800元/月/机构 | B端现金流+批量作答数据 |

**成本结构**：数字内容边际成本趋近于零（单份生成成本不足1元），主要成本是流量与内容审核。毛利结构允许把绝大部分预算投在获客和教研质量上。

## 五、护城河：四层，逐层加深

1. **产能层（可被追赶）**：AI出题引擎，无限量、零边际成本——这是入场券，不是壁垒。
2. **质量层（难追赶）**：一整套"校验门"质量体系（机器验算、查重、适龄审查、教研抽检），保证量产不出事故——多数同行会直接信任模型输出，我们不。
3. **诊断层（很难追赶）**：结构化"错误模式库"——把每道题的干扰项与学生的典型错误类型一一对应，这是诊断报告的产品力来源。该库由学术文献+国际教育开放数据+真实作答统计三源合成。
4. **数据层（不可复制）**：**作答数据飞轮**——每售出一份卷子都带回学生的逐题作答数据，用于实测每道题的难度与区分度，反哺出题质量。这是唯一别人拿不走的资产：中文小学题目目前没有公开的难度实测数据，谁先攒，谁定标准。

## 六、竞争格局与我们的位置

| 对手 | 他们卖什么 | 我们的差异 |
|---|---|---|
| 资料号（抖音/小红书，9.9元） | 静态题包 | 同样便宜，但多诊断与个性化 |
| AI学习机（2500~6000元） | 硬件+课程 | 十分之一价格，无需硬件，纯内容服务 |
| 题库SaaS（学科网等） | 服务学校和老师的B端工具 | 我们直接服务家长C端，且带诊断闭环 |
| 免费工具App（口算批改类） | 工具 | 我们卖持续的内容服务与方案，不是单点工具 |

**卡位**：比资料号贵一点、但有人工智能诊断；比学习机便宜十倍、但同样个性化。

## 七、发展路线（三年三段）

**第一年｜单品打透**：小学数学单点突破——计算专项包（市场验证过的最大单品类）→ 单元诊断包 → 学期订阅。目标：跑通漏斗、启动数据飞轮、沉淀首批实测题目参数。
**第二年｜横向扩展**：小学英语（词表封闭、最易系统化）、语文基础层（字词）依次进入；托管机构B2B（全国约58万家托管机构，日更练习是刚需，且是批量作答数据来源）；视飞轮转速启动初中数学。
**第三年｜纵深升级**：自适应练习（根据作答实时调题）、模拟考试产品、学年托管放量；初中科目扩展。

**学科扩展的优先级逻辑**：数学（答案可机器验算，确定性最高）→ 小学英语（词汇语法封闭）→ 语文基础层 → 语文语篇层（教研最重，放最后）。

## 八、合规红线（不可谈判）

1. 绝不做任何形式的学科类培训（真人辅导、直播课、一对一）——只卖数字化内容；
2. 宣传话术永不承诺提分/保过；
3. 永不使用教材课文原文、真题原文，只学结构；
4. 放量前办理《出版物经营许可证》（个体户可办，是淘汰小同行的壁垒）；
5. 未成年人数据：家长授权前置，最小化采集；
6. 平台规则按季度复核（内容不带码、触点合规、支付走官方接口）。

## 九、需要讨论的开发策略要点（本文档的目的）

1. **C端与B端的先后**：先C端跑通漏斗再B端，还是早期就签托管机构换取批量作答数据？
2. **定价锚点**：4.9元首单与199元学期订阅的定价是否需要A/B验证？
3. **打印寄送**：自建打印供应链 vs 外包，何时启动？
4. **教研投入**：错误模式库与知识点体系需要多少人工教研占比，是自建还是外聘顾问？
5. **节奏与资源**：第一年单点打透需要的资金/人力盘子，以及是否引入合伙人或投资。
