## 0. 一页结论

- **架构定义**：一个由**题型能力矩阵**定义的学科中立题型平台。核心平台只懂"作答交互、评分契约、素材、知识维度、证据账本"五类抽象；语文、数学、英语**一律以学科包（SubjectPack）形式存在，数学只是第一个包**；低/中/高学段差异一律以学段包（GradeBandPack）形式存在。核心代码零学科、零学段特判。
- **系统形态**：学科无关**模块化单体** + 四类可独立伸缩执行器（校验验算 Worker、渲染 Worker、估计批处理、AI 重负载 Worker）。不上微服务——首年规模（数十万题、数百万作答、晚高峰数千家庭）不需要，且微服务会撕裂内容/作答一致性。
- **一条主线**：**一切皆为不可变资产，一切结论皆可重算**。内容版本账、作答事件账、校验签发账三本账只增不改；分数、难度、掌握度、报告全是账本之上可替换方法重放的视图。
- **五个结构性设计决定**（本方案与"单学科方案+扩展包"思路的本质区别）：
  1. **统一内容模型**：题目来源由"生产谱系"统一描述，母题化等级（A 规则模板 / B 半模板装配 / C 素材驱动 / D 开放命题）是一等属性，四条生产线地位对等——母题 DSL 从"架构中心"变为 A/B 生产线的工具，阅读题组与作文不再是"特例通道"。
  2. **双类型注册表**：作答交互类型（12 种）与评分模式（7 种）是平台级正交类型系统，学科包只能复用与组合，不得私造作答结构。
  3. **约束集四维编译**：组卷约束 = 平台基础约束 ∪ 学科 overlay ∪ 用途 overlay ∪ 学段 overlay 的版本化组合，替代一维"用途 Profile"。
  4. **渲染三层组合**：交互组件（平台）× 学科组件（学科包）× 学段 Pack（注音/朗读/大字号），统一经 Render IR 双出口（打印 PDF / 在线组件）。
  5. **AI 能力总线**：LLM 分级路由 + TTS + 嵌入 +（预留 ASR）统一收口，成本台账与谱系贯穿内容生产、评分、音频三条链。
- **工程量**：约 **150–185 人月**，12–14 人工程团队 × 13–14 个月；三科教研内容团队（每科 3–5 人）另计。P0 以"30 个跨学科抽样题型走通全链路"的矩阵 spike 开局去风险。

## 1. 设计目标与架构公理

### 1.1 设计目标

| 维度 | 目标 |
|---|---|
| 学科 | 语文、数学、英语，三科首年共生（数学/语文先行，英语随听力线随后） |
| 年级 | 小学 1–6 全年级；内容按学段分批灌入（首批 3–4 年级全学科，随后 1–2、5–6） |
| 用途 | 练习（S1 静态周卷 / S2 扫码批改 / S3 在线练习）、诊断（S4）；测量（S5）能力内建、第二年开启 |
| 题型覆盖 | 小学全部题型（经清点：数学 22 种、语文 30 种、英语 23 种，约 75 种）无一遗漏地可生产、可组卷、可评分、可追溯 |
| 业务机制 | 题是数据卷是视图；校验门文化；十年数据飞轮；全链路可审计；未成年人合规 |

### 1.2 七条架构公理

| 公理 | 内容 | 工程推论 |
|---|---|---|
| **A1 题是数据，卷是视图** | 全系统只有一个内容资产域；任何产品形态不另立题库 | 试卷 =（内容快照， 约束集， 种子）的确定性输出 |
| **A2 校验门文化** | AI 与人工作物过同一扇门；不通过物理上无法入库 | 状态机 + 门证书 + 数据库层强制 |
| **A3 数据飞轮（十年）** | 原始作答只增不改；方法演进不推翻数据 | append-only 事件 + 开放归档 + 可替换批处理 |
| **A4 可追溯即入水口** | 凡触达用户的题必带可回流身份编码 | 无编码的渲染产物不得发布 |
| **A5 学科中立 by construction** | 核心模型从小学教育题型**全集**推导，而非从某一科的形状推导；数学也只能以学科包存在 | 核心域 CI 扫描禁止 import 任何学科包；学科逻辑只允许出现在包内 |
| **A6 学段是一等维度** | 低（1–2）/中（3–4）/高（5–6）学段差异（识字量、书写力、时长、合规、呈现）必须有类型化承载 | GradeBandPack 与学科包正交；禁止散落各处的年级 if 分支 |
| **A7 生产线多元对等** | 模板化是生产优化而非模型前提；素材驱动与开放命题是主要学科的**主形态**而非兜底 | 四条生产线共用同一入库服务、同一校验门、同一证据链 |

### 1.3 关键取舍总表

| 取舍点 | 本方案选择 | 否决项与理由 |
|---|---|---|
| 系统形态 | 模块化单体 + 4 类执行器 | 微服务：规模不需要，撕裂一致性与审计链 |
| 主存储 | PostgreSQL（JSONB + 分区 + 触发器 + 递归 CTE） | 图数据库/多模库：图谱千级节点、浅遍历；多一份存储多一份十年数据主权负担 |
| 内容模型 | 统一 Item + 生产谱系（tier 属性） | "母题中心 + 题组补丁"：使语文/英语主形态沦为二等公民 |
| 作答与评分类型 | 平台级双注册表（交互 × 评分） | 学科自定义作答结构：评分、证据、渲染、统计将逐学科断裂 |
| 母题载体（A/B 线） | 声明式 DSL（YAML/JSON Schema）+ 安全表达式求值器 | 代码模板（不可审阅、有安全面）、纯文本模板（表达不了约束与答案推导） |
| 组卷求解 | 离线 OR-Tools CP-SAT + 在线候选装填与启发式修补 | 纯贪心（满足不了诊断/测量硬约束组合）、全量 CP-SAT 在线（延迟不可控） |
| 渲染 | Render IR + HTML/CSS/KaTeX → 无头 Chromium | Typst 首年（品牌版式=CSS 由设计师迭代；Typst 列备选评估项） |
| 参数标定 | 先验/实测并存 + 贝叶斯收缩 + 分场景独立 | 单一难度值、跨场景混估（练习含提示重做，混估必致系统偏差） |
| 估计方法 | 可替换批处理：CTT+收缩 → Rasch/2PL → testlet | 首日 3PL/深度模型：数据不足、结论不可辩护 |
| 过程题/手写 | 结构化分步录入/答题区 + 拍照辅助人确认 | 全自动手写过程识别：精度风险摧毁当场报告可信度 |
| 作文评分 | 量规数据化 + AI 维度评分 + 四步上线 | 直接上线 AI 打分（不可辩护）、纯人工（成本不可持续） |
| 口语 | 注册接口、首年不实现 | 首年 ASR 口语评分（技术成熟度与成本不匹配） |
| 实例身份 | 内容寻址哈希 | 自增 ID：无法从构造上保证可复现与去重 |

## 2. 第一性原理：从小学题型全集推导核心抽象

### 2.1 题型能力矩阵（设计的经验基础）

对小学语数英全部题型穷尽清点（数学 22 种、语文 30 种、英语 23 种）后发现：**任何一道小学题都可沿五个正交维度被完整描述，且每个维度取值有限**：

| 维度 | 取值 | 规模 |
|---|---|---|
| V1 作答交互类型 | 单选/多选/判断、文本填空、数值填空、匹配连线、排序、简答、分步过程、写作、作图操作、（预留：书写抄写、口语） | 12 种（10 现役 + 2 预留） |
| V2 评分模式 | 精确匹配、数学等价、分步给分、关键点命中、AI 维度量规、人确认兜底、（预留：ASR 口语） | 7 种（6 现役 + 1 预留） |
| V3 素材类型 | 无 / 图 / 表 / 语篇 / 音频（可组合；含一材多题题组） | 5 类 |
| V4 母题化等级 | A 规则模板 / B 半模板装配 / C 素材驱动 / D 开放命题 | 4 级 |
| V5 知识与错误体系 | 学科包的维度树 + 错误类型库 | 纯数据 |

75 种题型全部映射为五维取值的组合（完整矩阵见附录 B）。三个关键归一洞察：

1. **听力不是新交互**——它是"音频素材 + 已有交互 + 限次播放策略"；低学段"教师读题"同理（题面 TTS，呈现层能力）。
2. **题组（一材多题）是语文/英语阅读的全部**——必须从"支持项"升为内容模型的主形态之一。
3. **真正需要的平台原语是有限的**——75 种题型归一到 12×7×5×4 的组合空间，矩阵的完备性即架构对小学阶段适用性的逐格证明；P0 阶段用 30 个抽样题型工程实证此矩阵。

### 2.2 统一内容模型（本方案的核心）

```
ItemIdentity（不变身份）
 └── ItemVersion（不可变内容快照，任何修改产生新版本）
      ├ objective        知识标注集{维度,编码} + 认知层级 + 多点关系声明(全部必需/可补偿) + 学段
      ├ interaction_ref  交互类型(注册表) + 交互参数(空位定义/步骤定义/作图约束/写作要求引用)
      ├ content          题面语义AST(块+槽位) + 素材引用(含题组结构)
      ├ scoring_ref      评分器(注册表) + 评分参数(答案程序/量规/关键点表)
      ├ error_bindings   选项/评分维度 → 错误类型 + 置信规则
      └ lineage          生产谱系：tier(A/B/C/D) + 生产线及版本 + 参数/素材源
                          + AI台账引用 + 门证书引用 + 签发人/时间

ItemTemplate（A/B级母题）── ItemTemplateVersion(dsl_version, spec)
      │ instantiate(params, seed)：确定性、内容寻址
      ▼ 产出 ItemVersion（实例即 Item；instance_id = H(模板版本, 规范参数, 引擎/学科包/语料库digest, locale)）

Material（素材：语篇/图/表/音频，独立资产，含来源与许可）
ItemGroup（题组/testlet：一材多题 + 组内顺序 + ≤6）
CorpusAsset（语料库：字库/词库/篇目库/句库/词表/音标库/函数库/图库；版本化、带许可、带谱系）
```

要点：

- **生产谱系统一**：A 级 Item 由模板实例化产生；B 级由"框架模板+语料库"装配产生；C 级由素材工坊创作（素材+题组）；D 级由命题工坊创作（命题蓝图+量规）。四级产物的 ItemVersion 结构完全一致——**"无槽母题"概念消失，tier 只是谱系字段**。母题 DSL 因此回归其真实位置：A/B 生产线的技术，而非架构的中心。
- **综合题分步（R-Q-15）**：分步过程题的交互参数携带步骤定义，每步可单独声明知识点标注与判分规则（`steps[] = {kp, scorer_params}`），步骤级标注与题目级 objective 并存，诊断可按步归因。
- **身份与版本（R-Q-20/26）**：Item 是不变身份；修改产生新版本；旧版本永不覆盖永不删除；退役是状态不是删除。
- **可复现（R-Q-03）**：A/B 级实例内容寻址，同一模板版本+同一参数任何时间重算同一 instance_id；C/D 级内容本身即不可变快照，天然可复现。
- **实例数量不封顶（R-Q-01）**：潜在实例空间组合爆炸不占存储；在线与组卷只消费**已发布实例池**，批任务预生成补池，用户链路永不临时调 AI 出题。
- **解析（R-Q-10/11/12）**：解析为独立资产，按错误类型组织（"你可能这样想"）、绑定 error_type_id 被多题复用；完整解题步骤随 ItemVersion 存储；"作答后才展开"由呈现层控制。

### 2.3 双类型注册表（平台级类型系统）

**交互类型注册表**：每种交互 = 作答采集 schema + 在线渲染组件 + 纸卷呈现规范 + 评分输入契约。首年实现 10 种：单选、多选、文本填空（多空）、数值填空（含单位/比较）、匹配连线、排序、简答、分步过程、写作、作图操作（简化：结构化元素点选/涂色，非自由画笔）。预留注册不实现：书写抄写（首年拍照+人确认过渡）、口语。

**评分器注册表**：每种评分模式 = 统一契约 `score(response, item_version, params) -> {维度分, 错误类型推断, 置信度, 证据, scorer_version}`。6 种现役：精确匹配（含多空分项）、数学等价（符号比较：分数化简/单位换算/数值容差）、分步给分（结构化步骤 rubric）、关键点命中（关键词/要点+规则）、AI 维度量规（作文/造句/口语交际）、人确认兜底（低置信汇聚人工队列）。

**纪律**：学科包只能**复用与参数化**注册表中的交互与评分器；新增类型须平台评审注册。作答结构一旦被学科私造，评分、证据链、渲染、参数统计将逐学科断裂——此纪律由 CI 契约测试强制。

## 3. 系统总体形态

### 3.1 分层全景

```
接入层    微信小程序(家长/学生，含低学段UI套件)      教研工作台(Web)
─────────────────────────────────────────────────────────────────────
应用层    练习 │ 诊断 │ 测量(预留) │ 扫码批改 │ 试卷服务 │ 报告 │ 生产管理
─────────────────────────────────────────────────────────────────────
领域核心（学科无关、学段无关，零特判；CI 扫描守卫）
  内容域   Item/版本/谱系/素材/题组/解析/语料库
  生产域   四条生产线：实例化引擎(A) │ 语料装配线(B) │ 素材工坊(C) │ 命题工坊(D)
  知识域   多维图谱/类型化边/错误类型资产
  校验域   门策略矩阵/验证器注册/门证书/抽检队列(AQL加严)
  组装域   约束集四维编译/求解/曝光账本/复习排程
  评分域   评分器注册表/分步Rubric/AI量规/错误推断/置信度分层
  交付域   Render IR/三层渲染组合/音频播放与二维码/追溯码
  数据域   作答事件/参数标定/掌握度/缺口盘点/退役建议
─────────────────────────────────────────────────────────────────────
扩展层    SubjectPack：数学包 │ 语文包 │ 英语包 …（学科存在的唯一方式）
          GradeBandPack：低学段包(1-2) │ 中学段包(3-4) │ 高学段包(5-6)（与学科正交）
─────────────────────────────────────────────────────────────────────
数据层    PostgreSQL(权威：JSONB+分区+触发器) │ 对象存储(卷/素材/音频/Parquet归档)
          Redis+任务队列(门编排/渲染/估计/TTS作业化)
横切      AI能力总线(LLM L0-L3 + TTS + 嵌入 + ASR预留；成本台账；PII剥离)
          合规层(匿名化/PII保险库/授权/时长与用眼保护) │ 审计哈希链 │ 可观测
```

### 3.2 部署单元（首年）

1. **core-api**：模块化单体（Python 3.12 + FastAPI），承载全部领域服务。
2. **validation-workers**：校验门编排与验证器执行（含 SymPy 独立验算），独立伸缩。
3. **render-workers**：静态卷/解析册/音频二维码渲染，批处理弹性伸缩。
4. **estimation-jobs**：参数标定、重判、缺口盘点、健康度批处理。
5. **ai-workers**：TTS 合成、AI 量规评分、强模型裁判等重负载 AI 作业。
6. **Web/小程序**：教研工作台（React）、微信端（原生或 Taro）。

数据库、对象存储优先托管；预留事务外箱接口，数据量到位后分析侧演进到 ClickHouse。

### 3.3 模块间硬规则（5 条）

1. 应用层只经领域服务访问数据，禁止跨域直读表。
2. 学科/学段相关逻辑只允许出现在 SubjectPack/GradeBandPack 内；核心域 CI 扫描禁止 import 任何包——边界渗漏即构建失败。
3. 所有出向用户的内容必须经交付域并携带追溯编码。
4. 作答结构与评分结构只能来自双类型注册表；学科私造类型在契约测试中失败。
5. 用户请求链路中禁止临时调用生成式 AI 出题；在线只消费已发布实例池。

## 4. 领域设计

### 4.1 生产域：四条对等生产线

四条生产线输出统一汇入"内容写入服务"（入库唯一路径，强制过校验门），共享谱系模型与教研工作台。

**A 线 · 实例化引擎（规则模板级）**
- 母题 DSL：YAML 存储、JSON Schema 约束、Linter 静态检查、自身版本化。六大块：`objective`（标注+多点关系）、`slots`（类型/取值域/槽间约束/**difficulty_relevant 标志**）、`variation_axes`（六变式轴→槽子集）、`presentation`（无逻辑插值+图形 DSL）、`answer_program`（安全表达式+学科函数库）、`distractor_rules`（干扰项=f(错误类型,槽值)，选项绑 error_type_id）。
- 表达式语言：纯函数、无 IO、无循环、确定性（自研极小求值器或 CEL）；学科复杂运算进**学科函数库**（版本化、全量单测），DSL 语法保持稳定。
- 确定性实例化 + 内容寻址 + 发布池按需物化（物化时快照渲染文本）。
- 受控变式：引擎按轴取槽子集重采样、其余冻结；**两条建模纪律**：①凡改变考查目标的参数必须拆母题，不得作为变式维度；②优先"按构造必然合法"的生成器设计。
- 难度相关槽越界自动触发难度重估任务。

**B 线 · 语料装配线（半模板级）**
- 模式：框架模板（结构参数化）+ 语料库填充。例：乱句排序 ← 句库抽样+正确语序记录；看拼音写词语 ← 词库×拼音规则；连词成句 ← 词表+语法模板；句式转换 ← 句型模板+句库。
- 语料库（CorpusAsset）为一等数据资产：版本化、带许可、带谱系；同时被干扰项生成（语文混淆图→形近字干扰）与校验门（适龄词表、课标词表）消费。
- 装配规则同样声明式、可审阅；产物带完整谱系（用了哪个语料库版本）。

**C 线 · 素材工坊（素材驱动级）**——语文/英语阅读、听力语篇的主生产线
- 流程：命题方向（知识点×体裁×难度×学段）→ AI 起草语篇（强模型档）→ **语篇难度分析**（字频/句长/生词率/体裁标签）→ 教研改写定稿 → 许可与来源登记 → 题组蓝图编排（一材多题、题序、testlet 标记）→ 校验门 → 签发。
- 工作台提供"素材→题组"编排视图与难度仪表盘；素材与题组分别过门。

**D 线 · 命题工坊（开放级）**——作文/口语交际/探究题
- 命题蓝图库：写作要求模板 + 量规模板 + 学段参数（字数区间/提示强度/图画素材）。
- 流程：蓝图 → AI/教研起草题目与参考量规 → 校验门（适龄/安全/量规完整性）→ 签发。评分量规随 ItemVersion 版本化。

**教研工作台（统一）**：四类生产线各自的审阅界面（母题=表单+实时预览+按轴抽样+边界枚举；素材=难度仪表盘+题组编排；命题=量规预览）、签发、抽检队列、覆盖缺口看板。教研审"行为与产物"，从不接触 DSL/配置文本。

### 4.2 知识域：多维图谱与错误类型资产

- **存储**：PostgreSQL 单库。`kp_node(node_id, pack_id, dimension, code, title, std_anchor, gradeband, status, valid_from/to, supersedes_id)`；`kp_edge(src, dst, rel_type, attrs, provenance)`；`relation_type` 元数据（directed/transitive/acyclic/symmetric）；`kp_closure` 传递闭包扁平表（热路径只读扁平表，递归 CTE 仅管理查询）；高频访问整图 MB 级快照入内存、按 graph_release 版本缓存。**不引入图数据库**（千级节点、万级边、1–3 跳浅遍历、十年运维成本不值）。
- **多维并行**：dimension 一等公民；题目标注 =（维度, 编码）对集合 + kp_set_mode（single/all_required/compensatory）+ 标注时 graph_release。
- **演进纪律**：code 一经发布冻结语义；修订=新编码+旧编码 deprecated+supersede 链；节点/边带有效期；查询支持"按当时图谱/映射到当前图谱"双模式；演进操作走审批流（治理问题，流程配套）。
- **三科维度设计**：
  - 数学包：四大领域（数与代数/图形与几何/统计与概率/综合与实践）× 知识点 DAG × 认知层级 × 核心素养标签；先修/易混淆/组成。
  - 语文包：四维（识字与写字/阅读与鉴赏/表达与交流/梳理与探究）× 字词图谱（形近/音近/义近/多音字，confusable 类边数千至万级）× 任务群标签 × 语篇属性（体裁/长度/难度级）。混淆边既是知识资产也是 A 线生产资料（干扰项生成）。
  - 英语包：级别（预备级/一级/二级）× 主题范畴（人与自我/社会/自然）× 语言知识（语音/词汇/语法/语用）× 技能（听说读看写）；形近词/近义/发音相近混淆边。
- **错误类型资产**：`error_type(pack_id, code, 定义, 判定规则版本, 证据计数)`；`error_type_kp` 挂接知识点（该点典型错误理解）；证据计数由数据域夜间批回填；判定规则随真实数据修正（版本化，历史推断可重放）。

### 4.3 校验域：门策略矩阵 × 插件 × 数据库级强制

- **三要素**：验证器插件（统一契约 `validate(artifact_ref, ctx) -> {pass|fail|review, evidence, confidence, validator_id+version, cost}`，注册制、按学科包提供）× **门策略矩阵**（按"学科包 × 产物类型"配置的有序验证器链：产物类型含实例/素材/题组/解析/**音频**/命题蓝图；策略版本化）× 产物状态机（draft→quarantined→published→retired）。
- **编排**：任务队列异步；廉价验证器先行（结构→许可→查重→学科验算→强模型裁判），阻断失败短路；留痕 `gate_run + verdict`（策略版本、各验证器版本、证据、耗时、成本）。
- **物理阻断**：发布事务必须持门证书（全部阻断项通过）；**数据库触发器强制** `published_at` 非空必伴随合法 `gate_certificate_id`，绕过写入服务直写即失败；authoring/serving 逻辑分区，组装服务只读 serving。
- **抽检**：按可配置比例分层送检（低学段、D 级产物、作文评分相关品类抽检率上调）；不合格自动对同母题/同批次/同素材批次**升级采样率（AQL 加严）**；结论回流验证器阈值调优数据集。
- **数学验算三层**：①双实现独立重算（验算器与实例化引擎不共享代码）②可解性穷举/属性采样（退化检查：除零/选项重复/干扰项=正解）③目标不变（objective 为槽值显式函数+技能集合恒等校验）；不可机器判定部分→强模型裁判+抽检，结论区分"已认证/UNPROVEN"。
- **学科验证器清单**：
  - 通用（平台）：Schema/Linter、来源许可、适龄与事实安全（规则+强模型+抽检）、四级查重（规范化哈希/结构指纹/MinHash/语义向量）、外部真题指纹（**法务共定义开放项**）。
  - 数学包：上述三层验算 + 量纲一致 + 图形数值一致。
  - 语文包：规范字表与笔顺校验、拼音规则校验（多音字语境）、事实核查（知识库+强模型）、语篇难度分级校验、病句检测、外部语料查重（**不抄课文原文**）。
  - 英语包：课标词表等级校验（词表外词必须标注或替换）、语法正确性（规则+强模型）、拼写、音标题规则校验、**音频质量校验**（发音正确/语速适龄/可懂度，强模型+人抽检）。
- **扩展边际成本**：新增校验项=实现接口并注册；新增学科=新插件包+一份门策略配置；编排/留痕/证书/抽检全部复用。
- **策略与图谱治理**：门策略自身的发布走灰度与回滚——新版本先影子运行，新旧结论差异率超阈值须人工审批后生效，旧版本一键回滚；图谱演进操作（编码废弃/映射）走审批流，签发权与流程由组织制度配套。

### 4.4 组装域：约束集四维编译 + 确定性求解

**编译模型**：`AssemblyProfile = base（平台通用约束） ∪ subject_overlay（学科包预设） ∪ purpose_overlay（练习/诊断/测量） ∪ gradeband_overlay（学段参数）`，四维均为版本化配置，编译时做**冲突检测**（如"约 20 题"与"每知识点≥3 题"在知识点多的单元不可同时满足时，按预置优先级裁决并记录理由——该冲突已列入业务开放项）。

**求解**：候选筛选（内容快照×发布状态×用途许可×曝光历史×学段许可）→ 离线出口跑完整 CP-SAT（硬约束可行解+软目标优化）→ 在线出口毫秒级"候选预算装填+加权启发式修补"。同一引擎同一题库，仅 Profile 与时间预算不同。确定性：给定（快照 id, Profile 版本， 种子）结果唯一，全程留档。**不可行必须返回冲突原因，不得静默放松**；缺口报告直接馈送覆盖缺口盘点。

**约束目录（全量）**：

| 类别 | 约束 | 机制 |
|---|---|---|
| 通用 | 目标正确率区间 | 按 P(correct\|item, 学生/cohort 参考分布, 场景) 预测，含参数不确定度惩罚；**冷启动降级**：无学生/cohort 数据时以纯先验区间+保守宽度代入约束求解，数据回流后按周自动收紧 |
| 通用 | 序列梯度单调 | 先修闭包+难度序列约束 |
| 通用 | 内容配比 | 新学/复习/易混淆交错（消费 confusable 边） |
| 通用 | 曝光互斥 | 同母题不同卷；跨期不重复（曝光账本双轨：静态按渠道×学科×版本×年级×周队列，在线按学生）；事务性曝光预留 |
| 诊断 | 孤立题强制存在且每点≥3；多点关系声明核验 | 候选筛选强制+CP-SAT 硬约束 |
| 测量(预留) | 双向细目表（内容×认知×题量×难度） | 单元格计数约束 |
| 通用 | 题组≤6 | 硬约束；作答事件带 testlet_id 供统计处理相关性 |
| 英语包 | 听力占比 30–40%、听力题置卷首、播放次数策略 | 学科 overlay |
| 学段包 | 低段题量上限/时长≤15 分钟/图形化比例/注音开关；3–6 年级单次≤60 分钟 | 学段 overlay |

**复习排程**：纯函数策略接口 + 版本化 ReviewPolicy 产出可重建 ReviewQueue；v1=固定间隔表（1/3/7/21 天）；v2 候选=FSRS（需改造：复习对象挂接知识点与错误类型归因，非闪卡照搬）。
**自适应**：首年不做，会话抽象为 `next_item(session_state)` 策略接口，次年换 CAT 不动会话框架。
**曝光能力边界（明示业务）**：社交公开 PDF 只能保证批次/周次级不重复；学生个人级不重复需记录家庭领取关系。

### 4.5 评分域：注册表 + 分层置信度

- **客观题**：精确匹配（含多空分项、序号、匹配对）；数学等价走符号比较（非字符串匹配）。
- **分步过程题**：首年输入形态为**结构化分步录入/答题区**（选择/填空步、页面定位标记、固定答题框），评分收敛为确定性问题；步骤定义随交互参数携带各自的知识点标注与判分规则（R-Q-15），诊断归因可定位到步骤；拍照手写识别仅"识别建议+人确认"录入提效，**不承诺任意手写草稿全自动分步判分**（若业务坚持，追加 30–50 人月且须先专项可行性验证）。
- **AI 维度量规**（作文/看图写话/造句/口语交际/英语书面表达）：量规即数据（维度+锚点描述+分值带，学科包定义、随题版本化）；强模型按量规打分+逐维理由；**上线四步**：公开基准验证→影子运行→抽检伴随→灰度；学段化抽检率（低段更高）；结论带置信度呈现、**不输出排名**。
- **错误推断**：选择题=选项→错误类型确定映射（模板 distractor_rules）；开放题=维度得分模式→错误类型规则表；多题证据**贝叶斯累积**，报告置信度即后验；**"选某项"是证据非因果**；compensatory 题只佐证不定位，定位必须由孤立题完成；推断规则版本化，真实发生率回流修正。
- **置信度四层分离**：图像识别/评分/错误推断/掌握结论各自独立记录，不得混为单一"AI 置信度"；低置信自动转人工队列（与抽检共用工作台）。

### 4.6 交付域：三层渲染组合 + 音频 + 追溯

- **Render IR**：内容与样式分离的中间态（Item AST + 题组结构 + 版式提示）。**三层组合**：交互组件（平台注册表）× 学科渲染组件（包内：数学图形 DSL/数轴/方格；语文田字格/拼音格/**拼音 ruby**/书写横线/修改符号；英语四线三格/词卡图/音频播放器）× 学段 Pack（注音开关/题面朗读按钮/大字号大按钮/数字键盘）。
- **双出口**：打印=Render IR → HTML/CSS+KaTeX+SVG → 无头 Chromium → PDF 试卷+解析册（品牌模板=页面模板+CSS+字体包，设计师可迭代）；在线=Render IR → 小程序/Web 组件。同源保证静态与在线题目行为、统计口径、追溯链一致。
- **音频**：TTS 生产线（AI 总线 TTS 档，多音色、语速按学段配置）产出音频素材（内容寻址、版本化、过音频校验门）；三种消费形态——在线内嵌播放器（**限次播放**，模拟考试只听 1–2 遍）、卷面音频二维码、低段题面点读。
- **追溯**：每卷唯一卷码+QR（码内只含卷 Spec ID+校验位，不含实例明文，防爬库）；每题印刷带纠错短码或签名 placement_token；`paper_item` 渲染时固化"卷→题→版本"映射；追溯链：题码→render_run→卷 Spec→ItemVersion→生产谱系→门证书→签发人。
- **周更批处理**：**教学上下文服务**（学科×教材版本×年级×教学周 → 已学范围快照，含推断置信度与教研人工修正）→ 组装（练习 Profile+周约束）→ 渲染 → 发布（不可变落库+对象存储内容哈希）。语文无版本维度（统编）；数学按版本建"单元结构映射"（不止顺序）；英语首年建 Top 版本（人教 PEP/新起点/外研/译林等）对齐数据，其余按区域灰度。
- **S2 针对性练习**：按错误类型**预渲染专项小卷库存**，诊断出类型即查表发放（不做按人实时渲染）。

### 4.7 数据域：事件、标定与飞轮

- **作答事件**：`response_event` 按月分区 append-only（DB 权限禁 UPDATE/DELETE+定期哈希锚定）。全要素字段：事件 id、匿名学生 id、item_version_id、**场景（practice/diagnosis/measurement）**、原始作答载荷（JSONB，含分步内容本身）、耗时、评分轨迹（scorer+version+过程+各层置信度）、错误推断（规则版本+置信度）、testlet_id、会话 id、播放行为（音频题）、时间戳。每日增量导出 **Parquet** 至对象存储+schema 注册表——十年可用的本质是原始数据不依赖任何单一厂商的开放归档。
- **参数标定**：`item_param(item_version_id, purpose_scope, source, params{difficulty,discrimination…}, sample_size, method_version, as_of)`；source ∈ prior_rule/prior_expert/measured_*；purpose_scope ∈ practice/diagnosis/measurement，**分场景独立估计禁止混估**；开放题按评分维度分别估计。**融合=贝叶斯收缩**（默认档：n<200 用先验 / 200–1000 精度加权收缩 / >1000 用实测；策略是配置可替换）；**练习场景数据因自适应暴露偏差仅用于粗校准与差题预警**。
- **估计器可替换**：纯批处理作业，输出契约固定；首年 CTT（正确率/点二列）+经验贝叶斯收缩 → 次年 Rasch/2PL（预留锚题等值）→ testlet 变体处理题组相关；每次运行绑定 model_version+代码 digest+**输入数据快照**+图谱 release；`ActiveModelPointer` 切换，历史报告引用当时模型。
- **掌握度**：Elo/带遗忘衰减加权正确率起步；在线轻量增量+夜间批权威双轨；可换 BKT/IRT。诊断报告结论置信度=后验；**允许输出"证据不足"**。
- **重判**：新 scorer 重放历史事件写平行 score_run，原序列不动；**增量重判**防成本爆炸；**每年一次全量重放演练**制度化。
- **飞轮闭环**：题目健康度（正确率异常/区分度低/干扰项无人选/耗时异常/场景间参数漂移/群体 DIF/评分争议率/错误映射无数据支持）→ 生命周期 ACTIVE→WATCH→QUARANTINED→RETIRED（退役不删除，签发制）；覆盖缺口盘点（知识点×认知×用途×学段×学科五轴热力图）← 组装缺口报告+库存盘点 → 驱动四线生产排期。

### 4.8 横切：AI 能力总线 / 合规层 / 审计

- **AI 能力总线**（原 AI 网关升级）：统一收口 LLM（L0 不用 AI / L1 弱模型初筛 / L2 强模型生产与裁判 / L3 双模型或 AI+人工复核）、TTS（多音色多语速档）、嵌入（查重/相似）、ASR（预留）。每次调用记台账（任务/模型精确标识/prompt 版本/token/时长/成本/关联产物 id）；按 item_revision 归集**单题全生命周期 AI 成本（含音频）**；PII 在总线前剥离；关键任务双供应商预案。
- **合规层**（由横切组件升格为设计约束）：学生仅 `student_alias_id`；直接标识入独立 PII 保险库（分离 schema/列级加密/白名单/独立审计）；家长授权前置（版本/范围/时间/撤回）；采集字段清单化；**代码层不提供跨用户排名查询**；远期同龄定位只做 k 匿名聚合；扫描件姓名 redaction 后再入模型；**会话层内置时长与用眼保护**（低段≤15 分钟、3–6 年级≤60 分钟建议阈值）；一二年级产品形态为练习/闯关而非"考试"；成绩等级化呈现不排名。
- **审计**：内容谱系+门证书+签发+组装留档+评分版本+AI 台账构成完整回溯链；审计日志哈希链防篡改；业务审计账本独立于运维日志。
- **端侧安全**：API 鉴权与防刷（请求签名+限流+异常设备识别）；试卷与音频资源走签名 URL 防盗链；追溯码采用不透明 token 防爬库（呼应 §4.6）；小程序端敏感操作二次确认。

## 9. 验收标准（机器可执行，建议写入实施合同）

1. 随机 10 万历史实例在冻结运行包中重放，内容摘要 100% 一致。
2. 绕过发布服务直写 serving 区必须在数据库层失败。
3. 任一打印题码可回溯：题目版本→生产谱系→校验记录→签发人→渲染版本。
4. **矩阵 spike 30 个抽样题型全链路通过**（生产→门→组卷→渲染→作答→评分→估计）。
5. 三科影子包接入验收：核心零 schema 迁移、零代码修改、组装零新分支。
6. 练习/诊断/测量走同一组装 API 与代码路径；不可行约束必须返回冲突原因。
7. 历史作答可用新评分器批量重判且原序列不变；任一参数估计可还原输入快照与模型版本。
8. 音频素材未经音频校验门不得入库；听力卷限次播放策略生效。
9. 已退役题不得进入任何新卷；过期许可素材不得用于新组卷。
10. 合规项：跨用户排名查询路径不存在；PII 不出保险库；会话时长保护触发正常。
