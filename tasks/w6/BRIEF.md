# W6 任务卡撰写简报（引擎解锁与飞轮加速波）

> 目标：让"无限出题"和"数据飞轮"从架构图变成可计量的事实。W6 出口 = 同一母题可产出结构互异的合格实例规模化产能，且组卷/参数/曝光三条飞轮回路真实闭环。
> 前置：**W5 全绿**（信任硬化）。理由：飞轮加速会大量写入内容与作答账，账本强制未闭合前加速=加速写脏数据。
> 输入：specs/constitution.md v2.0（A7 生产线对等、D3 内容寻址、D5 参数分场景、D6 估计器可替换）；W5 出口证据；旧 GitHub Issue #24/#26/#28 的重写结论（tasks/LEGACY-ISSUES.md）。

## 为什么这波最关键

四份审查报告里有一句共同结论：**"无限出题"目前退化为"加减乘除的有限扰动"**——学科函数库 19 个函数从未注入实例化求值器，所有母题只能用 BinOp 表达式。这一条直接决定护城河第一层（产能）能否成立，也决定 W8 内容规模化是否有意义。同时 D5/D6 在组卷侧未落地（仍读 lineage 先验而非 item_param），意味着"练习/诊断/测量三场景参数分离"目前只是表结构上的分离。

## W6 端到端出口定义

- **E2E-1（引擎解锁）**：抽 10 个数学母题，每个产出 ≥30 个通过校验门且**结构互异**（非仅数值扰动）的实例；产能报告含拒绝原因分布。
- **E2E-2（函数库安全）**：注入后的求值器仍拒绝全部既有 70+ 攻击向量；新增函数不得引入 IO/反射/循环。
- **E2E-3（DSL 静态防线）**：写错表达式语法/引用不存在的槽/引用不存在的模板 → linter 在入库前报错并定位到行。
- **E2E-4（D5 隔离）**：同一题在 practice / diagnosis / measurement 三场景下取到各自 `item_param`；人为污染一个场景的参数，另两个场景组卷结果不变。
- **E2E-5（曝光防重）**：同一学生连续 3 次领练习卷，重复题占比低于阈值；曝光账本在线可查。
- **E2E-6（冷启动）**：新入库题在 n<阈值 时按先验参与组卷且曝光受限；样本积累后自动切换到实测参数。
- **E2E-7（受控导入）**：一份外部语料经许可登记 → 素材化 → 母题化 → 过门 → 发布；跳过许可登记或跳过门的路径必须失败。
- **E2E-8（规模化）**：万题级题池下在线组卷 p95 达标；覆盖热力图能定位缺口并产出生产计划。
- **E2E-9（诊断力）**：给定一组含典型迷思的作答，弱项报告能给出错误类型级归因（不止对错），且归因可追到 error_bindings。
- **E2E-10（不退化）**：W0–W5 出口与实证矩阵全绿。
