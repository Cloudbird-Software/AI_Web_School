## 目标说明（≤5 行）
求值环境使用原始 params 而非规范化后的参数，fraction/decimal 类槽在表达式中可能崩溃或产生与内容寻址不一致的值；槽的 min/max 不校验；bool/string 转换踩 Python 陷阱（如 `bool("False") is True`）。这三条同时影响产能与 D3 内容寻址一致性。

## 验收标准（逐条可执行）
1. 求值环境统一使用规范化参数，与内容寻址所用的规范化函数**同源**（同一函数，不复制实现）。
2. 槽定义的 min/max/枚举约束在采样与校验两处生效，越界抛明确异常。
3. bool/string/decimal/fraction 转换语义显式定义并有表驱动测试（含 `"False"`、`"0"`、`"1e3"`、`"1/2"` 等陷阱值）。
4. fraction 槽端到端测试：DSL → 实例化 → 渲染 → 评分全链路正确。
