## 目标说明（≤5 行）
实现 DSL answer_program 使用的安全表达式求值器：只含纯函数、无 IO、无循环、无递归调用。
支持四则运算、比较、条件表达式、基本数学函数；函数调用只能命中白名单。
为学科函数库预留扩展点，但核心求值器保持学科无关。

## 验收标准（逐条可执行）
1. 求值器支持 `+ - * / // % ** < <= > >= == != and or not if/else` 与 `abs/min/max/sqrt` 等白名单函数。
2. 对 `__import__`、`open`、未声明标识符、循环语法抛出 `ExpressionUnsafeError`。
3. 确定性：同一表达式+同一环境，任意次求值结果一致（浮点除外）。
4. 单元测试覆盖 30+ 用例，包括除零、类型错误、非法函数。
5. 不 import 任何学科包/学段包。
