## 验证策略
本验证卡覆盖W1波次的三个数据库核心任务：统一内容模型DDL迁移（T-W1-002）、作答事件append-only写入（T-W1-005）、门证书模型（T-W1-006）。这三个任务均依赖T-W1-001/002，以数据库表结构和触发器为核心验证点。

验证层次：
1. **迁移可逆性验证**：make migrate-check 全绿（upgrade→downgrade→upgrade）
2. **DDL契约一致性**：字段名/类型/约束与契约逐项对照
3. **分区表验证**：response_event按月分区，主键含分区键
4. **append-only强制**：BEFORE UPDATE/DELETE触发器物理阻断修改
5. **ORM映射正确性**：插入/查询/JOIN操作正常
6. **循环外键处理**：item↔item_version等循环外键正确处理（DEFERRABLE或后置约束）

### 4. append-only触发器存在性
**验证SQL**：
```python
from sqlalchemy import text

# pg_trigger.tgtype 位掩码（PostgreSQL trigger.h）：
#   2=BEFORE, 4=INSERT, 8=DELETE, 16=UPDATE
# append-only 触发器必须是 BEFORE 且同时挂在 UPDATE+DELETE 上
@pytest.mark.asyncio
async def test_append_only_trigger_exists(async_session):
    result = await async_session.execute(text("""
        SELECT tgname, proname, tgtype
        FROM pg_trigger t
        JOIN pg_class c ON c.oid = t.tgrelid
        JOIN pg_proc p ON p.oid = t.tgfoid
        WHERE c.relname = 'response_event'
          AND NOT t.tgisinternal
    """))
    triggers = result.fetchall()
    assert len(triggers) >= 1, "应有append-only触发器"
    before_ud = [
        t for t in triggers
        if (t[2] & 2) > 0 and (t[2] & 8) > 0 and (t[2] & 16) > 0
    ]
    assert before_ud, "应有 BEFORE UPDATE+DELETE 触发器（BEFORE位+DELETE位+UPDATE位）"
    # 检查触发器函数名含raise/error/append
    trigger_func = before_ud[0][1]
    assert 'raise' in trigger_func.lower() or 'error' in trigger_func.lower() or 'append' in trigger_func.lower()
```

**测试用例**：`test_response_event_has_append_only_trigger`
