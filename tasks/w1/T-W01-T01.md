### 3. requirements.txt 一致性验证
**执行方式**（Python脚本）：
```python
import tomllib
import re

with open("pyproject.toml", "rb") as f:
    pyproject = tomllib.load(f)

deps = pyproject["project"]["dependencies"]
dep_names = set()
for dep in deps:
    name = re.split(r"[<>=!~[]", dep)[0].lower().replace("_", "-")
    dep_names.add(name)

with open("requirements.txt", encoding="utf-8") as f:
    for line in f:
        line = line.strip()
        if line and not line.startswith("#") and not line.startswith("-"):
            pkg = re.split(r"[<>=!~[]", line)[0].lower().replace("_", "-")
            dep_names.discard(pkg)

assert len(dep_names) == 0, f"以下依赖未在requirements.txt锁定: {dep_names}"
print("✅ requirements.txt 与 pyproject.toml 一致")
```

**验收标准**：脚本执行无断言失败。
