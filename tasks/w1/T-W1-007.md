## 目标说明（≤5 行）
实现 `src/core/content/writer.py`，提供 `publish_item_version()` ——入库唯一路径：创建 item（如新建）、写入 item_version、记录 lineage（生产谱系）、更新 current_version_id。**门强制规则**：若 item_version 的 `status` 设为 `published` 但未提供合法 `gate_certificate_id`，则 INSERT 失败（应用层校验 + DB CHECK 约束占位）。`CorpusAsset` 和 `Material` 的写入函数同样提供（结构同 item 族的只增不改模式）。

## 验收标准（逐条可执行）
1. `publish_item_version(item_id, version_data, gate_certificate_id=None)` 函数存在
2. 正常路径：创建 item + item_version，`current_version_id` 正确指向新版本
3. 门强制：`status=published` 且 `gate_certificate_id=None` 时插入失败（抛异常或返回错误）
4. `status=draft` 或 `status=quarantined` 不要求门证书
5. `lineage` 字段正确写入（至少含 tier、pipeline、signed_by、signed_at——契约 §5.2 required）；**gate_certificate_id 写入 `item_version` 列字段（唯一真源，lineage 内不重复存储，契约 §2.2）**
6. `publish_material()` 和 `publish_corpus_asset()` 函数骨架（签名正确，基本 INSERT 逻辑可用；material 写入走 material+material_version 两段式）
7. 单元测试：(a) 正常发布→回读一致；(b) 无证书发布→失败；(c) 有证书发布→成功且 `gate_certificate_id` 列字段正确写入；(d) 同一 item 两次发布→两个 version 均存在、current_version_id 指向最新 published；(e) 旧版本永不删除
8. `src/core/content/` 不 import 学科包/学段包
