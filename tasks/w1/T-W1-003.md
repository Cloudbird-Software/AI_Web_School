## 目标说明（≤5 行）
基于 T-W1-002 落地的 DDL，在 `src/core/models/` 下创建 SQLAlchemy ORM 声明式映射 + Pydantic schema。九实体为：`Item`、`ItemVersion`、`ItemTemplate`、`ItemTemplateVersion`、`Material`、`MaterialVersion`、`ItemGroup`、`CorpusAsset`、`CorpusVersion`。`ItemVersion` 六大块字段（objective/interaction_ref/content/scoring_ref/error_bindings/lineage）建模为 JSONB 列对应的 Pydantic 子模型。A/B 级内容寻址 `instance_id = H(...)` 逻辑在模型层实现为纯函数。

## 验收标准（逐条可执行）
1. `src/core/models/` 下每个实体一个 `.py` 文件，含 SQLAlchemy `Base` 映射 + Pydantic `BaseModel`
2. ORM 表与 T-W1-002 落地的 DDL 一致：`__tablename__` 正确、列名与类型匹配
3. `ItemVersion` 的六大块 JSONB 列均有对应的 Pydantic 子模型定义（含类型校验）
4. 内容寻址函数签名与契约 §3 逐字对齐：`compute_instance_id(template_version_digest: str, normalized_params: dict, pack_digest: str, engine_digest: str, corpus_digests: list[str], locale: str) -> str`——顺序与构成直接决定 instance_id 的值（D3），corpus_digests 为复数（语料库版本链）
5. 单元测试：至少覆盖 (a) ORM 映射可通过 `async_session` 插入/查询 item+item_version 记录；(b) 内容寻址同输入同输出；(c) 六大块 JSONB 序列化/反序列化往返一致
6. 核心域 `src/core/models/` 不 import 任何学科包/学段包（CI 静态扫描待 T-W1-008 出口验证）
