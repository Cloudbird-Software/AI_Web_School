## 目标说明
在一台干净机器上，cp .env.example .env 后 `make bootstrap` 能在 30 分钟内完成 PG16/Redis/MinIO 启动与逐项自检输出。任何一步失败给出明确 ❌ 与修复提示。

## 验收标准（逐条可执行）
1. `docker compose up -d --wait` 退出码 0
2. `make bootstrap` 输出含 ✅ PostgreSQL / ✅ Redis / ✅ MinIO 三行
3. `docker compose down && up` 后数据卷仍在（pg 中新建库表重启后可见）
