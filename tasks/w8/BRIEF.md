# W8 波次简报（规模与增长波）

> 出口：**单位经济性达标（单个付费用户的交付成本可持续）+ 内容规模与质量同时可持续增长 + 至少一条第二增长曲线（B 端托管或自适应能力）跑通试点**。
> 前置：W7 全绿（有真实用户、有真实付费、有可运维的生产环境）。
> 本波状态：**只出 Issue 台账，不物化任务卡**。W7 尾声时再拆卡，且需根据真实用户数据重排优先级（本台账是候选池，不是承诺）。

## 本波的判断原则

W8 之前所有决策靠推理，W8 之后所有决策靠数据。因此本波第一条纪律是：**每个 Issue 开工前必须先说明它对应哪个真实观测到的问题或机会**（来自 W7 的漏斗、访谈、成本账），无法说明的一律推迟。

## W8 工作流

| # | 工作流 | 内容 |
|---|---|---|
| S1 | 内容规模化 | 生产计划驱动的批量生产；教研协同流程；质量抽检常态化；三科覆盖度目标 |
| S2 | 单位经济性 | AI 成本、渲染成本、存储成本的分摊与优化；成本看板；每付费用户交付成本目标 |
| S3 | 自适应能力 | CAT 自适应选题正式上线；FSRS 或替代复习算法切换（基于 W6 预研结论）；效果 A/B 验证 |
| S4 | B 端托管试点 | 多租户隔离、机构/教师视角、班级作业与批量报告、数据边界与合规 |
| S5 | 增长闭环 | 获客渠道验证、推荐/裂变机制、续费与流失干预、家长口碑资产 |
| S6 | 平台韧性 | 容量规划、性能优化、成本告警、灾备升级、数据生命周期与归档 |
| S7 | 出口验证 | w8.sh + 单位经济性报告 + 试点结论 |

## W8 端到端出口定义

- **E2E-1**：批量生产作业按生产计划产出内容，抽检合格率达标且成本可核算。
- **E2E-2**：单位经济性报告：单个付费用户的完整交付成本（AI + 渲染 + 存储 + 支付）低于目标线。
- **E2E-3**：自适应选题上线后，效果指标（诊断效率/学习增益）相对基线有可统计显著的改善，且失败可回滚。
- **E2E-4**：多租户隔离：跨租户数据访问在任何路径下均失败。
- **E2E-5**：增长闭环：至少一条渠道的获客成本与留存数据可复算并支持决策。
- **E2E-6**：容量与成本告警在压力下按预期触发。
- **E2E-7**：W0–W7 出口与实证矩阵全绿。

## 非目标（W8 明确排除）

初中及以上学段扩展、新学科包（物理/化学等）、国际化、开放平台/API 商业化——这些进入 W9+ 讨论。
