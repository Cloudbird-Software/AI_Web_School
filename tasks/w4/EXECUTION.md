## 降级顺序（若产能不足）

按 BRIEF 非目标与影响面排序：

1. **S8 低学段包完整化（035–037）** → 保留 GradeBandPack L 参数包，渲染适配可简化。
2. **S3 C 线完整工坊（013–016）** → 保留语篇 schema 与门，AI 起草可降级为人工录入占位。

4. **S9 性能压测（038–039）** → 保留压测脚本框架，报告可简化为单次运行。
5. **S6 测量 CTT 报告（030）** → 保留测量卷产出，CTT 报告可延至 W5。
