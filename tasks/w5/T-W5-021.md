## 目标说明（≤5 行）
`PassageFactCheckValidator` 规则全过时仍返回 `review` 且类属性 `blocking=True`：正常语篇永远过不了门，C 线批量入库被结构性阻断。"永远失败"的规则比"没有规则"更危险——运维会以为系统正常。

## 验收标准（逐条可执行）
1. 规则未命中任何风险 → 返回 `pass`；命中可疑模式 → `review`；命中硬性错误 → `fail`。判定表在代码中显式列出。
2. 该验证器在门策略矩阵中的阻断性由策略文件决定（非类属性硬编码），默认配置写明理由。
3. 测试：干净语篇（含"春天来了，花儿开了。"这类）判定为 pass；含事实错误的语篇被拦；策略切换阻断性生效。
4. C 线端到端（语篇 → 题组 → 过门 → 入库）恢复可自动完成，W4 的 C 线测试全绿。
5. 不改门编排与证书签发逻辑。
