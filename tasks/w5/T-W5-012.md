## 目标说明（≤5 行）
保险库角色混乱（reader 有 INSERT 无 SELECT access_log，无独立 writer 角色）；且"每次读必留痕"的审计日志与业务事务同事务——业务回滚时审计静默消失，D7 承诺失效。

## 验收标准（逐条可执行）
1. 角色重整：`pii_vault_writer`（写身份）、`pii_vault_reader`（读身份+读审计）职责分离，最小权限，迁移可逆。
2. 审计写入改独立事务/独立连接，业务事务回滚不影响审计留痕；审计写失败必须抛出或告警，禁止静默吞掉（X12）。
3. 测试：读取身份后回滚业务事务 → `access_log` 仍存在；令审计写入失败 → 调用方可感知。
4. 无 PII 进入日志或异常消息。
5. 既有 PII vault 测试全绿。
