## 目标说明（≤5 行）

issue #34 §十要求的技术验证 spike：证明 baml-go runtime + sqlc + .baml 函数在本地与 CI 都能走通"生成→golden test→gate"闭环，为 T-W5-031 骨架与 W6 操作员/评价者 harness 扫清工具链风险（上游 #3690 等 codegen 边角问题在此暴露）。

## 验收标准（逐条可执行）

1. `baml generate`（或等价 CLI）产出 Go client，`go build ./...` 与 `go vet ./...` 全绿。
2. golden test：修改 .baml prompt（哪怕一个字符）→ 快照测试红；还原 → 绿（BAML-1 可执行实证）。
3. `sqlc generate` 幂等：对同一 schema/queries 二次生成零 diff（SQL-2 可执行实证）。
4. Makefile 提供 `baml-generate` / `sqlc-generate` 目标；CI 能在无 npm 全局环境复现生成物（锁版本）。
5. spike 结论（含上游 bug 规避清单）写回本卡备注或 ADR-0004 附录。
