## 目标说明（≤5 行）
PDF 导出以 `--no-sandbox` 运行无头浏览器并以"文件存在"判定成功：前者让任意注入的 HTML/JS 拥有过高权限，后者会把 0 字节/半截 PDF 当成功产出发给用户。

## 验收标准（逐条可执行）
1. 去掉 `--no-sandbox`；若运行环境确需降权，改为容器内非 root + seccomp 说明，并在卡内记录理由（禁止无说明保留）。
2. 渲染输入统一走既有 Render IR/模板，禁止拼接未转义的外部字符串到 HTML。
3. 成功判定：进程退出码为 0 **且** 产物非空 **且** PDF 头合法 **且** 页数 ≥1，任一不满足抛异常。
4. 测试：模拟渲染进程失败/产出 0 字节 → 抛异常不返回路径；正常路径产出可打开的 PDF（可复用既有 slow 标记）。
5. 既有渲染与周更批处理测试全绿。
