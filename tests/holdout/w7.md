> 意图（人类视角）：**北极星兑现**——真实的小学生用自己的账号做完练习，拿到的弱项报告指得出"哪里弱、接下来练什么"；

> 前置：W6 holdout 全绿；学生端可访问（`HOLDOUT_STUDENT_URL`）；`HOLDOUT_BASE_URL` 指向后端。

## H-W7-1 学生全链闭环：注册→家长授权→练习→作答→弱项报告
- 意图：V1（终点是真实小学生拿到弱项报告）；A9（在线链路与内容资产同级）
- 类型：machine

```bash
BASE="${HOLDOUT_BASE_URL:-http://localhost:8080}"
[ -n "${HOLDOUT_TOKEN:-}" ] && [ -n "${HOLDOUT_ALIAS:-}" ] || { echo "需要 HOLDOUT_TOKEN / HOLDOUT_ALIAS（已完成家长授权的测试学生）"; exit 1; }
code=$(curl -s -o /dev/null -w '%{http_code}' -X POST "$BASE/sessions" \
  -H "Authorization: Bearer $HOLDOUT_TOKEN" -H 'Content-Type: application/json' -d '{"kind":"practice"}')
[ "$code" = "200" ] || [ "$code" = "201" ] || { echo "授权学生开局失败（$code）"; exit 1; }
curl -sf "$BASE/reports/weakness/$HOLDOUT_ALIAS" -H "Authorization: Bearer $HOLDOUT_TOKEN" \
  | grep -qE '"weak|kp|knowledge' || { echo "弱项报告不含知识点维度内容"; exit 1; }
```

## H-W7-2 量规评分已完成灰度切换：真实分数来自注册表评分器
- 意图：issue #34 §4.3 四步（shadow→共识认证→灰度→漂移监控）；铁律 3
- 类型：machine

```bash
docker compose exec -T db psql -U "${POSTGRES_USER:?}" -d "${POSTGRES_DB:?}" -tA -c "
SELECT count(*) FROM score_run sr
WHERE sr.scoring_trace->>'scorer_ref' IS NULL
   OR sr.scoring_trace->>'model_version' IS NULL" \
| grep -qx '0' || { echo "存在无评分器注册引用或缺模型版本的真实评分（灰度切换不干净）"; exit 1; }
```

## H-W7-3 埋点漏斗真的在收数：练习漏斗五步事件齐全
- 意图：A10（增长闭环内建）；W7 出口"埋点漏斗"

