## H-W6-1 数学量产达标：≥10 个母题、每个 ≥30 个合格实例
- 意图：issue #34 §七 W6 出口（M2）；"结构互异"判定 = 同母题下发布实例的内容摘要是两两不同（唯一率 100%）
- 类型：machine

```bash
docker compose exec -T db psql -U "${POSTGRES_USER:?}" -d "${POSTGRES_DB:?}" -tA -c "
WITH pubs AS (
  SELECT lineage->>'template_id' AS tpl, md5(content::text) AS digest
  FROM item_version WHERE status='published' AND lineage ? 'template_id'
), per_tpl AS (
  SELECT tpl, count(*) AS n, count(DISTINCT digest) AS u FROM pubs GROUP BY tpl
)
SELECT count(*) FILTER (WHERE n >= 30 AND u = n) FROM per_tpl" \
| awk '$1 >= 10 {ok=1} END {exit !ok}' \
|| { echo "满足「≥30 实例且摘要全唯一」的母题不足 10 个"; exit 1; }
```

## H-W6-2 语文半确定题型全链走通：操作员生成→评价者验→入账
- 意图：issue #34 §七 W6 出口；§四（LLM 产出永远是 draft，过门才入账）
- 类型：machine

```bash
docker compose exec -T db psql -U "${POSTGRES_USER:?}" -d "${POSTGRES_DB:?}" -tA -c "
SELECT count(*) FROM item_version iv
WHERE iv.status = 'published'
  AND iv.lineage->>'source' = 'synthetic'
  AND iv.lineage->>'operator' IS NOT NULL
  AND iv.lineage->>'pack_id' LIKE 'chinese%'
  AND EXISTS (SELECT 1 FROM gate_verdict gv JOIN gate_run gr ON gr.run_id = gv.run_id
              WHERE gv.detail->>'validator' = 'llm_judge'
                AND gv.detail->>'verdict' = 'pass'
                AND gr.target_id = iv.item_version_id)" \
| awk '$1 >= 1 {ok=1} END {exit !ok}' \
|| { echo "语文无一条「LLM 生成 + llm_judge 通过 + 已发布」的完整链路证据"; exit 1; }
```

## H-W6-6 LLM 成本有硬顶：预算熔断真实生效
- 意图：issue #34 §九（LLM 成本失控 → 预算硬顶 + 超限熔断）
- 类型：machine

```bash
BASE="${HOLDOUT_BASE_URL:-http://localhost:8080}"
[ -n "${HOLDOUT_TOKEN_OPS:-}" ] || { echo "需要 HOLDOUT_TOKEN_OPS（运维主体凭证，用于把预算调到 0 触发熔断）"; exit 1; }
curl -sf -X PUT "$BASE/ops/llm_budget" -H "Authorization: Bearer $HOLDOUT_TOKEN_OPS" \
  -H 'Content-Type: application/json' -d '{"hard_limit_cny": 0}' >/dev/null
code=$(curl -s -o /dev/null -w '%{http_code}' -X POST "$BASE/internal/ai/generate" \
  -H "Authorization: Bearer $HOLDOUT_TOKEN_OPS" -H 'Content-Type: application/json' \
  -d '{"fn":"holdout_probe","input":{}}')
[ "$code" = "429" ] || [ "$code" = "503" ] || { echo "预算为 0 时 AI 调用未被熔断（返回 $code）"; exit 1; }
```

## H-W6-7 语料铁律：语文英语题目的内容源只来自入库语料

