## H-W8-1 三科覆盖度可核算：热力图数据来自真实题库
- 意图：M4（覆盖度热力图达标）；A7
- 类型：machine

```bash
docker compose exec -T db psql -U "${POSTGRES_USER:?}" -d "${POSTGRES_DB:?}" -tA -c "
SELECT count(DISTINCT kn.subject) FROM kp_node kn
WHERE EXISTS (SELECT 1 FROM item_kp ik JOIN item_version iv ON iv.item_version_id = ik.item_version_id
              WHERE iv.status = 'published')" \
| awk '$1 >= 3 {ok=1} END {exit !ok}' \
|| { echo "有已发布内容覆盖的学科不足 3 个（语数英覆盖度不达标）"; exit 1; }
```

## H-W8-2 单份内容全成本可核算且含 LLM 成本
- 意图：M4（单位成本含 LLM 成本预算护栏）；issue #34 §九
- 类型：machine

```bash
docker compose exec -T db psql -U "${POSTGRES_USER:?}" -d "${POSTGRES_DB:?}" -tA -c "
SELECT count(*) FROM information_schema.tables
WHERE table_name IN ('ai_call_ledger','llm_call_ledger')" \
| awk '$1 >= 1 {ok=1} END {exit !ok}' || { echo "AI 成本台账缺失，全成本无从核算"; exit 1; }
```

## H-W8-3 漂移监控在岗：评分一致率持续被计算
- 意图：issue #34 §4.3 第 4 步（跌破阈值自动降回 shadow；阈值定义见 §十一：周滑动一致率 <0.85 降级）
- 类型：machine

```bash
docker compose exec -T db psql -U "${POSTGRES_USER:?}" -d "${POSTGRES_DB:?}" -tA -c \
  "SELECT count(*) FROM shadow_score WHERE created_at > now() - interval '30 days'" \
| awk '$1 > 0 {ok=1} END {exit !ok}' \
|| { echo "近 30 天无 shadow 评分记录（漂移监控的对比基线不在岗）"; exit 1; }
```
